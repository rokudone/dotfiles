# Slide Design Rules

These rules override the pptx skill's design advice. Follow them on every slide, no exceptions.

## Layout Rules (MANDATORY)

1. **No unnecessary line breaks** — if text fits on one line, keep it on one line. Never break text into multiple lines for "visual effect." Only break when the text box width physically forces it.
2. **Consistent margins on all four sides** — pick a margin value (e.g., 0.5") and use it identically for top, bottom, left, and right across ALL slides. Never let one side have more space than another.
3. **Fixed title position** — the title must appear at the exact same x, y coordinates and the same font size on every slide. Never move the title around between slides.
4. **Center-align when whitespace is awkward** — if a layout creates unbalanced empty space, center the content (both horizontally and vertically) rather than leaving it off-center with dead space on one side.
5. **Minimal decoration** — do not attempt complex decorative elements (accent bars, colored panels, overlays, numbered badges, card borders). Keep it simple: background color, text, and images. If you cannot execute a decoration cleanly, do not add it.
6. **Full-contrast text only** — never use light gray, muted, or faded text colors. All text must be fully readable: white on dark backgrounds, black/near-black on light backgrounds. No "subtle" or "secondary" text colors.
7. **Same layout across similar slides** — when multiple slides serve the same purpose (e.g., feature showcases), use the identical layout for all of them. At most, mirror left/right. Do not vary layouts per slide unless you can execute it flawlessly.

## Avoid

- Don't vary layouts per slide — use the same layout for same-purpose slides
- Don't use gray or muted text — all text must have full contrast
- Don't add decorations you can't execute well — no accent bars, colored panels, card borders, or overlays
- Don't move titles around between slides
- Don't break text onto multiple lines when it fits on one
