会話を振り返り、ユーザーが即座に文脈へ復帰できる形で状況を報告する。

## 手順

1. 会話履歴を頭から見て、ユーザーが最初に依頼したことと、そこから変化した目的を掴む。
2. 直近の作業単位（今どのファイル・どのタスクに手を付けているか、完了済みか途中か）を特定する。
3. 自分（アシスタント）の最後の発話を探し、そこにユーザーへの問いかけが含まれていたかを確認する。含まれていたら、その問いが何を確認していたのかを再構成する。
4. 下記フォーマットで報告する。

会話履歴の中に既にある情報だけで答える。確認のためにファイルを読み直したりコマンドを実行したりしない。

## 出力フォーマット

```
## この会話でやっていること
（1〜3文。最初の依頼と、今の目的がずれているならそのずれも書く）

## 直近やっていたこと
1. （直近の作業。完了したものと途中のものを分けて書く）

## あなたへの最後の問いかけ
（問いの内容と、選択肢があるならその選択肢。答え待ちであることを明示する）
```

問いかけが無かった場合は「あなたへの最後の問いかけ」の見出しごと省き、代わりに「次にやること」として、こちらが次に着手する予定を1〜3行で書く。

## 制約

1. 未回答の問いかけを勝手に自分で解決して先へ進まない。報告だけして止まる。
2. 会話に出ていないことを推測で埋めない。曖昧な箇所は曖昧なまま「〜が不明」と書く。
3. 全体で20行程度に収める。読み返すためのものであり、議事録ではない。
